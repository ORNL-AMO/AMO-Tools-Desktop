Auxiliary Equipment Help
Electricity used by equipment that supports the process heating system, such as fans, pumps, and conveyors. It is calculated separately from the heat balance, at the facility electricity cost.
These inputs and calculations are the same as the Electricity Reduction calculator (Calculators > Utilities > Electricity Reduction), applied to each piece of equipment.

Annual Operating Hours
Number of hours per year the equipment is on. Be sure to include normally scheduled overtime.
Minimum Maximum
0 hrs/yr 8760 hrs/yr
} @case ('measurementMethod') {
Method of Measurement
Choose the method to be used to determine electricity consumption.
Power Meter Method - The best way to measure electrical consumption is with a power meter. Manufacturer's data on lights can be entered as if the measurements were done with a power meter.
Multimeter Reading - Multimeter measurements are the second most accurate means of measuring electrical consumption and are accurate for DC and for AC (when combined with the plant's uncorrected power factor).
Nameplate Data - Motor nameplate data can provide a reasonable estimation of the energy that motors are consuming but are not as accurate as a power meter. Nameplate data does not tell the user how heavily loaded the motor is.
Other Method – Choose this option if you are using a different method to find the electricity consumption.

} @case ('powerFactor') {
Power Factor
Use the uncorrected power factor of the plant as an average value. This number is available from the plant electrical specialist. For a modification this value should be the same as the baseline unless specific actions were taken to improve power factor.
Do not model savings from power factor correction without reducing the average current simultaneously.
} @case ('ratedMotorPower') {

} @case ('variableSpeedMotor') {

} @case ('lineFrequency') {
Line Frequency
The main supply frequency from the utility. In North America the standard frequency is 60 Hz. Elsewhere, 50 Hz is often the standard.
} @case ('operationalFrequency') {
Operational Frequency
Input the operating frequency which has been adjusted by the variable speed motor drive.
} @case ('motorAndDriveEfficiency') {
Motor & Drive Efficiency
The ratio between the amount of mechanical work the equipment performs and the electrical power it consumes to do the work represented by a percentage.
} @case ('loadFactor') {
Percent Loaded
The amount of work the equipment is doing compared to the nameplate. Typical load factor is 75% for a motor and 100% for an electric heater. This value cannot be found on the nameplate.
} @case ('power') {

} @case ('energy') {
Energy
Enter the off sheet calculated value for annual energy consumption in kWh.

The number of identical units in the specified system. When units of different size have been combined previously enter 1.
